02

Add ENI to your wallet

Pick your wallet below. Each tab has step-by-step instructions for that specific wallet.

MetaMask

// Browser extension or mobile app
  1. Open MetaMask

    Click the orange fox icon in your browser toolbar, or open the MetaMask app on your phone. Make sure you're logged in.

  2. Open the network menu

    At the very top of the wallet you'll see a small button showing your current network — usually "Ethereum Mainnet" with a colored circle next to it. Click it. A dropdown of networks appears.

  3. Add a new network

    Scroll to the bottom of the dropdown and click + Add network. On the next screen, click Add a network manually at the bottom.

  4. Fill in the form

    Paste the values from Section 01 above. You only need these five fields:

    · Network Name: ENI Mainnet
    · New RPC URL: https://rpc.eniac.network
    · Chain ID: 173
    · Currency Symbol: EGAS
    · Block Explorer URL: https://scan.eniac.network

  5. Save and switch

    Click Save. MetaMask will switch to ENI Mainnet automatically (or prompt you to switch — accept it). You'll see "ENI Mainnet" at the top of your wallet. Done.

// You're doneYour wallet is now connected to ENI. You can send and receive EGAS, interact with ENI dApps, and view your transactions on the block explorer.

Bitget Wallet

// Mobile-first multi-chain wallet
  1. Open Bitget Wallet

    Launch the Bitget Wallet app on your phone, or open the browser extension. Make sure you're logged in.

  2. Tap the network selector

    At the top of the home screen, you'll see the current network name (e.g. "Ethereum" or a network icon). Tap it to open the network list.

  3. Add a custom network

    Scroll to the bottom of the network list. Tap + Add Custom Network (sometimes labeled Manage Networks → Custom).

  4. Fill in the network form

    · Network Name: ENI Mainnet
    · RPC URL: https://rpc.eniac.network
    · Chain ID: 173
    · Symbol: EGAS
    · Block Explorer: https://scan.eniac.network

  5. Confirm and switch

    Tap Confirm. The network is saved. Open the network list again and select ENI Mainnet to switch to it.

// You're doneENI Mainnet now appears in your network list. Switch to it any time you want to interact with the ENI ecosystem.

Token Pocket

// Asia-popular DeFi wallet
  1. Open Token Pocket

    Launch the Token Pocket app on your phone, or open the browser extension. Make sure you're logged in.

  2. Open the network selector

    From the wallet home screen, tap the chain name or chain icon at the top of the screen to open the network selector.

  3. Add a custom EVM network

    In the network list, look for the Custom tab or the + icon. Tap it to add a new EVM-compatible network.

  4. Enter the network details

    · Network Name: ENI Mainnet
    · RPC URL: https://rpc.eniac.network
    · Chain ID: 173
    · Symbol: EGAS
    · Block Explorer: https://scan.eniac.network

  5. Save and select

    Tap Save or Confirm. Then select ENI Mainnet from the chain list to switch.

// You're doneYou're now on ENI Mainnet. Your wallet will display your EGAS balance and route all transactions through ENI.
